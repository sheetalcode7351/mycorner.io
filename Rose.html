Creative Coding

Creative coding combines programming and creativity to create interactive digital experiences, animations, and visual experiments. Through p5.js, I explored motion, randomness, interaction, and generative design while learning how code can become a medium for artistic expression and storytelling.

1. Panda Toy Character

This project recreates a panda toy using basic shapes, colors, and symmetry in p5.js to explore digital illustration and composition.

2. Interactive Face Generator

An interactive face sketch where eye movement, zoom effects, and color changes respond to mouse interaction and animation.

3. Interaction Experiment

A creative coding experiment where shapes and motion respond dynamically to left and right mouse movement using p5.js.

Made with ❤️ using HTML, CSS & p5.js
